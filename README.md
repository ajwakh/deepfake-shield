# 🛡️ Deepfake Shield

Deepfake Shield is a project that helps detect fake (AI-generated or manipulated) images and videos, so people can tell what is real and what is not.

## Why this project?

Deepfakes are becoming more realistic and are often used to spread false information, scams, and harassment. Deepfake Shield aims to give people a simple tool to check media before trusting it.

## Features

- Detect deepfake images
- Detect deepfake videos
- Show a result: Real or Fake
- Simple and easy to use

> Note: This project is under development. Features are being added step by step.

## Getting Started

### Requirements

- Python 3.8 or higher
- Git

### Installation

```bash
git clone https://github.com/ajwakh/deepfake-shield.git
cd deepfake-shield
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
